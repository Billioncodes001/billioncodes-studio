# Visual assets

This independent recreation is not an official brand property.

- Typography is self-hosted from Fontsource's open font packages. Corresponding font license files are included in `public/fonts/`.
- Interface illustrations and geometric/poster studies are original CSS compositions.
- `docs/preview.webp`, `docs/desk.webp` and `docs/proposal.webp` are actual browser screenshots of this application using isolated synthetic records, not images of an original company's website or generated interface mockups.
